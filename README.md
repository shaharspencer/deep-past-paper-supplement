# Deep Past Paper Supplement

This repository contains the anonymized supplementary data for the paper’s Old Assyrian machine-translation analysis.

- `human_annotations_synthetic_test_set.md`: Expert labels for the synthetic test set, including number accuracy, entity accuracy, and truncation/omission.
- `human_annotations_unseen_test_set.md`: Expert labels for the unseen test set, including number accuracy, entity accuracy, and truncation/omission.
- `rerun_scores_synthetic_test_set.md`: Per-system translations, BLEU × chrF++ geometric means, and energy measurements for the synthetic test set.
- `rerun_scores_unseen_test_set.md`: Per-system translations, BLEU × chrF++ geometric means, and energy measurements for the unseen test set.
- `kaggle_source_catalog.md`: Index of the Kaggle writeups, discussions, and notebooks used as evidence in the survey.
